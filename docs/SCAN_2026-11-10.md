### What the extension already gets right

- `hook.js` is data-free: key-name tripwires only, values re-read from the DOM.
- No XSS: every `innerHTML` is a static template or `PV_ICO` constant; vault
  strings go through `textContent`.
- No `eval`/`new Function`/remote script; no `externally_connectable`, so a web
  page cannot message the extension at all.
- Save prompts use closed shadow roots; saves are filed under the sender
  frame's registrable domain; create/update/delete are popup-only and
  reprompt-armed rows need a single-use token.
- Reprompt-armed logins still require `confirmSensitive` before a fill
  (`content.js:1506`), which caps B1/B2.

## 4. Crypto and vault format — 0 P0/P1, 11 P2

Verified good: fresh 192-bit random nonce at all 11 AEAD sites; `OsRng` only
(no `thread_rng`/seeded RNG anywhere); Argon2id `64 MiB / t=3 / p=4` as
constants (a hostile container cannot inflate KDF memory); HKDF domain
separation over every header field, so cross-vault key substitution fails
closed; verify-before-decrypt; rev/prev-hash chain inside the AEAD; tmp+fsync+
rename saves; decoy cannot persist.

Hardening list (details in `A-crypto.md`):

1. `A-01` plaintext JSON envelope never zeroized — `storage.rs:487`, `:682-740`.
2. `A-02` `Vault` derives `Debug` — `models.rs:593` (CVV, SSH private key,
   passkey seed, `totp_unlock_secret`, `attachment_root` would print).
3. `A-04` `?` before `argon2_key.zeroize()` — `crypto.rs:369-370`, `:299-304`.
4. `A-03` no AAD on container AEAD — `crypto.rs:190`, `:315`, `:432`
   (currently safe, fragile for the next header field).
5. `A-05` `fs::read(...).unwrap_or_default()` resets `rev=1`/`prev_hash=""` on
   a transient read error — `storage.rs:485`.
6. `A-06` unbounded `fs::read` of the container — `storage.rs:639`
   (`panic = "abort"` on allocation failure).
7. `A-08` unbounded Argon2 params from `ext_pin.dpapi` — `ext_pin.rs:139`.
8. `A-07` temp-file leak on a failed save; no directory fsync — `shredder.rs:108`.
9. `A-09` non-constant-time HMAC compare in the access log — `access_log.rs:294`.
10. `A-10` `meta.version` is never checked — silent forward-compat rewrite.
11. `A-11` `CachedLogin` derives `Debug` with a plaintext password —
    `offline_cache.rs:40-45`.
